# BarberCRM (BS-CRM) — Рабочее место барбершопа

Современная, быстрая и отзывчивая CRM/PWA система для барбершопов, спроектированная по принципу **Calendar-First & Desktop-First + PWA**.

---

## 🚀 Как запустить проект

```bash
npm install            # зависимости (+ автоматически prisma generate)
cp .env.example .env   # если .env ещё нет
npm run db:push        # схема БД SQLite
npm run db:seed        # демо-данные (УДАЛЯЕТ все данные!)

npm run dev            # dev-режим
# или
npm run build && npm run start
```

Приложение: **http://localhost:3000** → откроется страница входа.

### Проверки качества

```bash
npm run typecheck      # TypeScript
npm run lint           # ESLint
npm run build          # production-сборка
# API + security тесты (нужен запущенный сервер с MESSAGE_FAILURE_RATE=0 и сид-данные):
MESSAGE_FAILURE_RATE=0 CRON_SECRET=test npm run start &
CRON_SECRET=test npm test   # BASE_URL=http://127.0.0.1:3000 по умолчанию
```

Тесты (`tests/api.test.js`) проверяют авторизацию и сессии, CSRF, изоляцию салонов (IDOR),
права ролей на уровне API, движок записей (часовой пояс, рабочие часы, пересечения, статусы,
гонки), клиентов/поиск и напоминания. Тесты создают собственные данные (второй салон удаляется в конце).

## 🆕 Регистрация нового барбершопа

Страница **/register** (ссылка «Зарегистрироваться» на странице входа): название, адрес,
часовой пояс, имя владельца, email и пароль. Создаётся отдельный салон (данные полностью
изолированы), аккаунт владельца, 3 шаблона сообщений и 3 базовые услуги; при галочке
«Я тоже стригу» владелец сразу появляется в календаре. После регистрации — сразу вход и
подсказки первых шагов. Отключить публичную регистрацию: `REGISTRATION_ENABLED=false`.

## 📊 Отчёты (только владелец)

Раздел **«Отчёты»**: периоды «Сегодня / 7 дней / 30 дней / этот и прошлый месяц» или свои даты.
Выручка (по завершённым визитам, фактическая цена), число визитов, средний чек, доля no-show,
выручка по дням (по месяцам для длинных периодов, с таблицей), по барберам — визиты, выручка,
no-show и загрузка (занятое время / рабочие часы по графику), клиенты — новые, постоянные,
повторные визиты, популярные услуги. Все даты — в часовом поясе салона.

## 🔐 Вход и роли

Вход по email и паролю (`/login`). Пароли хранятся как scrypt-хэш, сессия — случайный токен
в httpOnly-cookie (в БД хранится только его SHA-256), выход и смена пароля завершают сессии.
Демо-пароль всех сид-аккаунтов: `password123` — **смените его** (меню аккаунта → «Сменить пароль»;
при входе с демо-паролем показывается предупреждение).

| Пользователь | Роль | Email |
| :--- | :--- | :--- |
| Эльдар Алиев | `owner` | `owner@barberstudio.az` |
| Нигяр Мамедова | `admin` | `admin@barberstudio.az` |
| Руслан / Ахмед / Эльвин | `barber` | `ruslan@…`, `ahmed@…`, `elvin@barberstudio.az` |

Права (проверяются на сервере, не только скрытием кнопок):

| Действие | Owner | Admin | Barber |
| :--- | :---: | :---: | :---: |
| Календарь, записи всех мастеров | ✅ | ✅ | только свои |
| Клиенты | ✅ | ✅ | только свои клиенты |
| Архивировать клиента | ✅ | ✅ | ❌ |
| Изменить цену записи | ✅ | ✅ | ❌ |
| Услуги и цены (каталог) | ✅ | ❌ | ❌ |
| Сотрудники-барберы | ✅ | ✅ | ❌ |
| Администраторы/владельцы, смена ролей | ✅ | ❌ | ❌ |
| Настройки салона, шаблоны, запуск напоминаний | ✅ | ✅ | ❌ |
| Отчёты (выручка) | ✅ | ❌ | ❌ |
| Удаление всех записей/сообщений | ✅ | ❌ | ❌ |

Все данные изолированы по салону (`shopId`): чужие id возвращают 404.

## ⏰ Часовой пояс и напоминания

* Рабочие часы, день недели и время в сообщениях считаются в **часовом поясе салона**
  (Настройки → Часовой пояс), независимо от часового пояса сервера. Интерфейс тоже показывает
  время салона на любом устройстве.
* Автонапоминания (24ч и 2ч) проверяются встроенным планировщиком каждые 5 минут
  (`src/instrumentation.ts`). При нескольких экземплярах приложения: `REMINDER_SCHEDULER=off`
  и внешний cron `POST /api/cron/reminders` с заголовком `Authorization: Bearer $CRON_SECRET`.
* Защита от дублей, максимум 3 попытки, резервный канал при ошибке основного.
* ⚠️ Шлюз WhatsApp/Telegram/SMS пока **симулируется** (`src/lib/notifications.ts → deliver`);
  для реальной отправки подключите провайдера. Ручные сообщения открывают WhatsApp (wa.me).

## ⚡ Реализованный функционал (Definition of Done)

### 1. Календарь (Calendar First)
- **Day View** (по умолчанию) с колонками для каждого барбера и временной шкалой (09:00 – 21:00).
- **Week View** с переключением режима в 1 клик.
- **Быстрое создание записи**: клик по свободному времени мгновенно открывает Drawer с уже подставленными барбером, датой и временем.
- **Drag & Drop**: перетаскивание записи на новое время с модальным окном подтверждения переноса и автоматической проверкой конфликтов.
- **Фильтр барберов**: переключение видимости барберов с цветовыми индикаторами.
- **Operational Summary**: плашка оперативной сводки над календарем (всего записей, завершено, ожидает, отменено, no-show).

### 2. Создание записи (Right-Side Drawer)
- Выезжающая правая панель (400–480 px).
- **Autocomplete поиск клиента** по имени или номеру телефона с отображением даты последнего визита.
- **Inline создание клиента**: добавление нового клиента без перехода на отдельную страницу.
- **Повтор услуг (1-click)**: если клиент уже был, система предлагает кнопку «Повторить услуги» из прошлого визита.
- **Мультиселект услуг** с автоматическим суммированием длительности и стоимости.
- **Ручная корректировка цены и длительности** без изменения глобального каталога услуг.
- **Защита от пересечений**: проверка занятости барбера (`new_start < existing_end && new_end > existing_start`).
- **Проверка рабочих часов**: валидация смены барбера и выходных дней.

### 3. Карточка записи (Appointment Details)
- Просмотр деталей визита, назначенных услуг, цены и комментариев.
- Быстрый селектор статусов (`Ожидает`, `Завершён`, `Не пришёл`, `Отменён`).
- Плашка **No-Show** с кнопкой «Записать снова».
- Кнопка «Напоминание» (отправка сообщения в WhatsApp).
- Статусы «Завершён» и «Не пришёл» доступны только после начала визита; отменить можно только ожидающую запись.

### 4. Клиенты (Clients)
- Таблица для Desktop и карточки для Mobile.
- Дебаунс-поиск по имени и нормализованному номеру телефона.
- Фильтр **«Давно не был»** (> 30 дней с момента последнего визита).
- **Карточка клиента**:
  - Всего визитов и давность последнего визита;
  - Автоматически рассчитываемый блок **«Любимые услуги»**;
  - Персональные заметки мастеров (с автором, датой и текстом);
  - Полная история предыдущих записей со статусами;
  - Кнопки «Записать снова» и «Написать».

### 5. Барберы и графики работы (Barbers & Schedules)
- Карточки мастеров с цветовой индикацией и графиком.
- Настройка расписания по дням недели (Пн–Вс): выбор времени смены (начало/конец) и отметка выходных дней.

### 6. Каталог услуг (Services)
- Список услуг с длительностью и ценами.
- Мягкая архивация (`isActive = false`): услуги не удаляются физически, сохраняя целостность старых записей.

### 7. Напоминания и сообщения (Messages & Reminder Engine)
- **Журнал сообщений**: история отправки через WhatsApp, Telegram, SMS со статусами `sent` и `failed`.
- **Повтор отправки (Retry)**: возможность повторить отправку сбойного сообщения в 1 клик.
- **Шаблоны**: шаблоны напоминаний за 24 часа, 2 часа и ручных сообщений.
- **Палитра переменных**: кликабельные теги `{имя}`, `{дата}`, `{время}`, `{барбер}`, `{услуги}`, `{адрес}`, `{название_барбершопа}`.
- **Автоматический запуск**: движок проверки записей и рассылки напоминаний.

### 8. Горячие клавиши (Keyboard Shortcuts)
- <kbd>N</kbd> — Быстрое открытие создания новой записи.
- <kbd>/</kbd> — Глобальный поиск клиентов и записей.
- <kbd>T</kbd> — Переход к сегодняшней дате в календаре.
- <kbd>Esc</kbd> — Закрытие любого открытого Drawer или Modal.

### 9. PWA & Mobile UX
- Веб-манифест (`manifest.json`) и Service Worker (`sw.js`).
- Мобильная нижняя навигация (Bottom Bar) с крупной центральной кнопкой `+`.
